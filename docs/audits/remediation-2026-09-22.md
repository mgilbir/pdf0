# Remediation of the 2026-09-22 audit

This index maps every finding of
[codebase-audit-2026-09-22.md](codebase-audit-2026-09-22.md) to the pull
request and the commits that address it, and says what state each is in. Like
the report, it is a record of a point in time: the state of the stack of pull
requests #295–#312 and #313 (the documentation, this index's own, whose
number is a placeholder), not a description of the code.

It was built from the commits of the stack, which cite the IDs they address,
and from the pull-request descriptions, which list what each left undone. A
citing commit is not proof that every site was closed — the 2026-07-26 audit's
remediation showed that twelve times — so each entry says which sibling sites
the commit names, and "partially fixed" points at the residual the commit or
the pull request records. Where the two disagree, the entry says so.

Statuses:

- **fixed** — the finding as written is addressed, at every site the commit
  names.
- **partially fixed** — addressed, with a residual that the commit or pull
  request documents; the entry says what it is.
- **fixed in the tree; the owner decides on the files** — what the repository can do is done, and the rest is files in the owner's own checkout.

No ID lacks a citing commit or a pull-request mention.
